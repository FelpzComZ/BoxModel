## 🎯 Sobre o Projeto

Este repositório contém meus estudos e práticas sobre o **Box Model** do CSS. O Box Model é um dos conceitos mais fundamentais do desenvolvimento front-end, pois define como os elementos HTML ocupam espaço na página.

Aqui eu explorei na prática como funcionam as propriedades:
- `content` (conteúdo)
- `padding` (preenchimento interno)
- `border` (borda)
- `margin` (margem externa)

## 🖥️ Tecnologias Utilizadas

- **HTML5** - Estruturação do conteúdo
- **CSS3** - Estilização e aplicação do Box Model
